# 口播稿规则与硬校验

## 1. 结构

- 用 `scripts/视频脚本_版本A.md` 保存带章节标题的版本：
  `**第N章: 标题**`（N 用 一、二、三…），标题独立成行且**不进 TTS**。
- 正文按章节连写，通篇像一个人娓娓道来，不要大纲、不要 Markdown 符号。
- **正文禁止出现章节标题、Markdown 符号、括号、破折号**；章节头只用于视觉标题，绝不能进 TTS。

### 字数口径（唯一标准，其他位置不再重复）

| 版本 | 时长 | 字数参考 | 每章 |
|---|---|---|---|
| B 站长版横屏 | 5–8 分钟 | 1500–2400 字（每分钟约 260–300 字） | ≥300 字，成段不断章 |
| 抖音竖屏短版 | 60–90 秒 | 300–450 字 | 只留最炸 3 点 |

- B 站长版低于 4 分钟直接打回重做，不允许 1 分钟短视频凑数；引流片是额外产物，不能替代主片。

## 2. 固定开场与结尾（按平台分流）

- **B 站长版**：第 1 章 hook 一两句之后必须出现：
  `欢迎回来，我是言同学。`
  全片只能出现这一次。结尾使用 `config.json` 的 `fixed_copy.ending_line`，固定句后
  再接一句**本集专属**互动引导。
- **抖音短版**：0–3 秒直接甩钩子，全片禁止出现 `欢迎回来，我是言同学。`；结尾不进
  固定告别句，直接用本集互动问题收束。
- `fixed_copy` 是开场和结尾的唯一来源；文档示例、生成稿与校验脚本都必须读取 config，
  不得各自写死。

## 3. 数字与标点

- 年份一律中文数字，且用「零」不用「〇」：`2024` → `二零二四`，`2006` → `二零零六`。**交 TTS 前对 chapters.json 检查 `〇`，有则替换为 `零`。**
- 型号/非年份数字按口语转中文，例如 `MINI EV` 拆字母、`LZ 110` 写成 `LZ 一一零`；正文中英文/数字之间保留一个空格。
- 禁止破折号 `—`、连字符 `-`、下划线 `_`、括号 `()`，一律用逗号或句号。
- 正文不要出现 `第N章` 字样和任何标题句。

## 4. 去 AI 味（写完必须人工过一遍，发现即改写）

### 4.1 排查这些 AI 壳
- 二元对比壳：不是 A 而是 B / 不仅是 A 更是 B / 与其说 A 不如说 B。
- 路标连接词：值得一提的是、值得注意的是、总而言之、综上所述、由此可见、首先…其次…最后、通过…方式、不仅…而且。
- 空洞断言：本质上、核心在于、底层逻辑、真正重要的、这个世界需要…。
- 规整排比：段落等长、每段「观点 + 解释 + 总结」、对仗工整的排比句；结尾不空喊口号式反问。

### 4.2 改写手法
- 删过渡词，长短句交错，单句尽量不超过 15 字，像真人聊天。
- 给具体细节（年份 / 动作 / 画面），保留观点与事实，不编造数据。
- 加口语化语气词：「你想想」「说实话」「很多人不知道」「我跟你说」。
- 加入主观判断和情绪：「这台车当时真的离谱」「谁能想到呢」。
- 允许小的逻辑跳跃和口语停顿，不要每段结构完美。

## 5. 平台脚本差异（同选题出两版，分开写稿）

### 5.1 B 站长版横屏（1920×1080，5–8 分钟）
- 第一句先抛钩子，第二句接「欢迎回来，我是言同学」，再慢慢铺垫。
- 完整历史 + 所有细节，节奏舒缓；标签用汽车历史、品牌故事、科普类大词。
- 每 5 秒一个信息点，情绪有起伏，不平铺直叙。

### 5.2 抖音竖屏短版（1080×1920，60–90 秒）
- **0–3 秒直接甩反常识钩子，禁止自我介绍**（不写「欢迎回来，我是言同学」开场）。
  - 错误：「欢迎回来，我是言同学，今天我们来讲迈凯伦 F1」
  - 正确：「1998 年它跑出 391 公里每小时，这个纪录保持了 12 年，法拉利都追不上。」
- 砍掉所有历史铺垫，只讲最反常识的 3 个冷知识点。
- 结尾直接抛问题引导评论，不说「感谢观看」（例：「你开的车跑过 30 万公里吗？评论区说」）。
- 标签用搜索词（「汽车冷知识」「涨知识了」「为什么 XX」），不用大词。
- 校验时必须传 `--platform douyin`；该模式不要求也不允许固定欢迎语和长片告别句。

## 6. 钩子与涨粉引导结构

### 6.1 钩子
- 钩子 5 选 1（每集至少用 1 个）：数字冲击 / 反常识 / 揭秘式 / 情绪共鸣 / 对比反差。
- 每章开头先抛一个悬念或结论，不要平铺直叙讲历史。
- 结尾最后 10 秒加行动召唤，如「你觉得这台车值不值？评论区聊聊」。

### 6.2 系列化与涨粉
- 开头加「言同学汽车帝国系列第 X 集」，结尾留「下一集我们讲 XX，关注我别错过」。
- 结尾固定结构：1 个互动问题引导评论 + 1 个关注理由（关注后能看到什么后续内容）；不说「喜欢请点赞投币收藏」空话。
- 评论区可故意留一个小争议点 / 小错误，吸引车迷纠正辩论、提升互动率。
- 粉丝动态写一个车迷共鸣钩子（如「有没有小时候坐过这台车的？举个手」）。

## 7. 切分与校验

```powershell
python <skill>\scripts\parse_script.py <项目目录> --platform bilibili
python <skill>\scripts\parse_script.py <项目目录> --platform douyin
```

产物：`scripts/视频脚本_版本A_clean.md`、`scripts/口播流水_版本B.txt`、`audio/chapters.json`。校验要点：

- 章节数、每章字数符合第 1 节目标；
- 纯口播文本开头 100 字内含开场白（抖音短版除外）；
- 以结尾句收尾；
- 无标题行 / 无括号 / 无破折号残留；
- 无 `〇`。
