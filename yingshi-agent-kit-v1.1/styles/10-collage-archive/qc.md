# 包 A 验收清单

## 元素层

- [ ] 半调网点看得见（放大到 200% 有点阵，不是连续调）
- [ ] 成品墨量 25–45%（太浅发灰、太重成黑洞）
- [ ] 撕边有 3–5px 抖动，不是直边
- [ ] 沿裁切边有一圈更浅的纸色，和背景纸能分开
- [ ] 每个元素都有柔和投影，层与层之间有物理厚度
- [ ] 抠图失败时已降级为矩形照片碎片，且不出明显白边

## 合成层

- [ ] 底纸上有污渍、纸纤维、暗角，不是纯色块
- [ ] 主图占画面宽 45–52%，中心落在右三分线
- [ ] 至少一块碎片出血（超出画框）
- [ ] 全片同时出现的文字标签 ≤ 3 条
- [ ] 红绳经过图钉，顺序从左到右
- [ ] 成型后只有一次极缓推近，没有循环漂浮

## 渲染层

- [ ] `npx hyperframes check` 0 error（`container_overflow` 的 info 可接受）
- [ ] 首帧是空纸面，元素逐件进入，不是整体淡入
- [ ] 逐秒抽帧平均亮度没有接近 0 的黑帧
- [ ] 逐秒 std 从个位数一路升到 45+，说明画面在持续加信息
- [ ] 成片 1920×1080 / 30fps，时长与 `data-duration` 一致

## 合规

- [ ] 每个元素的出处与授权写进 `elements/manifest.json`
- [ ] 优先 Public domain / CC0；CC BY 类必须保留署名
