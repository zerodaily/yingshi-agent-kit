# 包 0 验收清单

## 画面层

- [ ] 每个画面都有一张配图，没有纯文字页
- [ ] 底纸是米黄旧纸（`#f2e8d3` 系），带颗粒纹理，不是纯色块
- [ ] 配图带朱红木框画卡
- [ ] 全片没有混入异风格图（写实照、3D、现代扁平插画）
- [ ] 相邻两个画面不复用同一张图

## 合成层

- [ ] 大标题用楷体、正文用宋体
- [ ] 画面内所有文字都是 HTML/CSS 渲染，不是图像模型画的
- [ ] 竖屏版核心内容压在抖音安全区内（高度 15%–70%）
- [ ] 竖屏标题 ≥76px、正文 ≥44px
- [ ] 言同学 IP 固定在右下角安全区

## 渲染层

- [ ] `index.html` 引用的每一张图在磁盘上真实存在（缺图会静默黑屏）
- [ ] `npx hyperframes check` 0 error
- [ ] 逐秒抽帧没有黑帧
- [ ] 成片分辨率与 fps 与 `data-duration` 一致

## 发布物料

- [ ] 6 个尺寸封面齐全，且每张都出现言同学 IP
- [ ] 封面配色没有搞反（米黄底 + 主色，不是深底 + 米白字）
