# 包 0 · 复古纸墨（retro-paper）

## 一句话

米黄旧纸底上放一张朱红木框画卡，下面压 HTML 文字。产线的**内置默认画风**，新项目不选画风就是它。

## 适用 / 不适用

- 适用：人物、品牌史、社会话题，需要娓娓道来讲故事的长片。
- 不适用：揭秘 / 犯罪类（用包 A）、科技 / 商业科普（用包 B）。

## 与两个拼贴包的根本区别

包 0 **不使用分层舞台**。画面是「一张配图 + 文字卡」的整图形态，
不像包 A / 包 B 那样把一个画面拆成多个元素逐件组装。

因为这一点，包 0 **不提供** `motion.yaml`、`elements/manifest.json`、`library/`——
这三样是分层舞台专用的。它的画面形态由 `assets/starter_index_16x9.html` 承载。

## 令牌

### 配色

| 用途 | 值 |
|---|---|
| 底纸 | `#f2e8d3`（米黄旧纸） |
| 主色（标题 / 双线 / 正文） | `#2d5a3d`（深绿） |
| 印章 | `#b03a2a`（朱红） |
| 画卡边框 | 朱红木框 |
| 颗粒纹理 | 叠一层 fractalNoise，`opacity .12`，`mix-blend-mode: multiply` |

### 字体

| 用途 | 字体 |
|---|---|
| 大标题 | `KaiTi`（楷体） |
| 正文 | `SimSun`（宋体） |

### 画面结构

1. 米黄旧纸底 + 颗粒纹理 + 双线 / 朱红点缀；
2. 上方一张 `artplate` 配图（朱红木框画卡）；
3. 下方 HTML 文字卡。

文字一律 HTML/CSS 渲染，任何情况下不交给图像模型。

## 出图

前缀见 `prompts/still-prefix.txt`。包 0 是**单前缀出图**，没有独立后缀文件——
前缀字符串末尾的「无任何文字」已经是收尾约束。

## 节奏

一段 5 分钟口播约 20 个画面；时长更长时按 2–3 秒 / 画面扩张，
不要复用同一张图做相邻两个画面。

## 禁忌

- 不做纯文字页，每个画面必须有一张配图；
- 不混入异风格图；
- 渲染前必须校验 `index.html` 引用的每张图在磁盘上真实存在（缺图会静默渲染成黑屏，这是最高频事故）。

## 交付规格

横屏 1920×1080 / 30fps；竖屏 1080×1920 由 `vertical_transform.py` 派生。
