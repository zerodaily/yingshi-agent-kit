# 包 B 验收清单

## 元素层

- [ ] 半调网点清晰（8px 栅格），不是连续调
- [ ] 裁切边干净，抖动 ≤1px，没有撕裂感
- [ ] 沿边有一圈奶油白描边（3px），与色场分开
- [ ] 成品墨量 25–45%

## 合成层

- [ ] 一屏色块 ≤3，底色只用一种
- [ ] 大标题 ≤3 词，词级入场
- [ ] 行高 ≥1.15，没有文字重叠告警
- [ ] 竖屏安全区：核心内容在高度 15%–70%，底部 25% 不放关键信息
- [ ] 标题字号 ≥76px，正文 ≥44px
- [ ] 成型后只有一次推近

## 渲染层

- [ ] `npx hyperframes check` 0 error
- [ ] 首帧是纯色场（元素未入场）
- [ ] 逐秒抽样没有黑帧，std 从个位数升到 60+
- [ ] 1080×1920 / 30fps，时长与 `data-duration` 一致
