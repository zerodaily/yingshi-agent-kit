# Vibe 风格精准描述（风格 B 的调性卡）

> 这份文件解决的是「说不清」的问题：**vibe 不是一个模板，是一套有硬内核、可调质感的风格。**
> 硬内核不能动（动了就不是 vibe）；质感可以调（调了还是 vibe）。
> 规格正文（叙事结构、锚词法、交付要求）仍以 `style-library.md` §B 为唯一权威，本文件只补「怎么说准」。

---

## 1. 先记一句话

**vibe = 纸面质感 + 一个锚词 + 音乐第一个重拍砸出它。**

三件事缺一件都会跑偏：
- 没有纸面质感 → 变成普通文字动画；
- 没有锚词 → 变成科普解说，观众记不住；
- 不踩重拍 → 高潮变成"字幕换行"，白瞎音乐。

---

## 2. 硬内核（不可调，动了就不是 vibe）

| # | 约束 | 为什么 |
|---|---|---|
| H1 | **无口播**，字幕承担全部叙事 | 有配音就变成路线 1 口播片 |
| H2 | **锚词 2–4 字**，写文案前先定 | 全片的钉子；术语不是锚词 |
| H3 | **高潮砸在音乐第一个重拍**，误差 ≤2 帧 | 情绪曲线跟音乐走 |
| H4 | **全片爆点最多两次**（重拍 + 中段小爆点） | 第三次就廉价了 |
| H5 | **不弹跳、不旋转、不花字、不快切** | 这四条是"像宣传片"的主要来源 |
| H6 | 字幕中文 ≤18 字，中英双行，每句 3–5 秒 | 长了就变成读文章 |

判据很简单：**抽掉音乐，片子还成立吗？**（成立=叙事够硬）**抽掉锚词，片子还剩什么？**（什么都不剩=锚词没咬住）

---

## 3. 可调的七个维度（Dials）

每一维给三档，**档位是起点不是枷锁**——可以只改其中一项。

### D1 纸感
| 档 | 长什么样 | 适合 |
|---|---|---|
| 羊皮纸（暖） | 米黄→浅褐渐变，纤维感明显，边缘偏暗 | 怀旧、时间感、人物命运 |
| 宣纸（净） | 近白微暖，纤维细，几乎无脏点 | 概念、原理、想显得"干净" |
| 旧报（灰） | 灰绿/灰黄，颗粒重，暗角深 | 档案、调查、冷峻事实 |

### D2 镜头运动
| 档 | 参数 | 观感 |
|---|---|---|
| 静止呼吸 | `camZoom: 0` | 像定格照片，全靠元素与字幕推进 |
| 极缓推（默认） | `camZoom: 0.05` | 几乎察觉不到的靠近，20 秒只推 5% |
| 慢平移 | 加 x 位移，`camZoom ≤0.03` | 像镜头在纸面上滑，慎用，容易"飘" |

别用：推拉快、变焦跳、旋转。

### D3 节奏
| 档 | 每句停留 | 适合 |
|---|---|---|
| 慢 | 4–5 秒 | 情绪重、想让观众停一下 |
| 标准 | 3–4 秒（默认） | 大多数题材 |
| 紧 | 2.5–3 秒 | 信息密度高，但不要低于 2.5 |

**一句 = 一个画面事件**。一句话跨两个画面，观众会追不上。

### D4 色彩
| 档 | 主色 | 强调色 | 用法 |
|---|---|---|---|
| 单墨 | 近黑墨 | 一点朱红（≤5% 画面） | 最克制；红只给"要你注意的那一下" |
| 暖褐 | 深褐墨 | 赭石/土黄 | 怀旧、纸质书感 |
| 冷灰 | 墨绿黑 | 暗红 | 档案感；别用正红，会跳 |

铁律：**没有纯白、没有纯黑**（纯白会像 PPT，纯黑会像片头）。强调色只做点睛，不做底色。

### D5 图形语言
| 档 | 元素 | 适合 |
|---|---|---|
| 几何抽象（默认） | 点、线、方块、圆 | 原理、群体、结构 |
| 剪影 | 人/物剪影，边缘手绘感 | 人物、命运、故事 |
| 毛笔笔触 | 墨迹、飞白、笔锋 | 情绪、转折、"写"出来的感觉 |
| 线稿 | 细线勾勒，留白多 | 机制、拆解、说明 |

同一片只用一种。混两种 = 视觉上没有"一个作者"。

### D6 字幕
| 档 | 位置 | 观感 |
|---|---|---|
| 居中下（默认） | 底部居中，留 120px | 稳、纪录片常规 |
| 左下 | 左侧 180px 内边距 | 更像"旁白在画面外"，留白多 |
| 竖排 | 右侧竖排 | 风格强，但 18 字以内很难排，慎用 |

暗背景用浅字、亮背景用深字，永远加一层极轻阴影。

### D7 声音
| 档 | 构成 | 适合 |
|---|---|---|
| 纯氛围 | BGM + 一层底噪，无点状音效 | 极简、冥想感 |
| 氛围+点睛（默认） | BGM + 5–8 处短音效（重拍、转场、结论、片尾） | 大多数 |
| 音乐主导 | BGM 更响，音效只留重拍那一下 | 音乐本身很强时 |

铁律：音效**短、轻、干净**，不抢音乐；同一秒不叠两个音效。

## 4. 三个预设档位（直接用）

对应模板 `CONFIG.look` 的三个值，切换后纸色、墨色、字幕位置、锚词字号一起变。

| 预设 | look | 一句话 | 适合题材 | 一句话点单 |
|---|---|---|---|---|
| **P1 羊皮纸·默片** | `parchment` | 暖黄纸、深褐墨、字幕居中 | 怀旧、人物、时间 | 「羊皮纸默片版」 |
| **P2 宣纸·单墨** | `linen` | 近白纸、乌黑墨、一点朱红、字幕偏左 | 原理、概念、心理学 | 「宣纸单墨、字幕走左下」 |
| **P3 旧报·档案** | `archive` | 灰绿纸、重颗粒、深暗角、暗红点睛 | 调查、事实、反常识 | 「旧报档案版，颗粒重一点」 |

三个档位都满足硬内核，差别只在"这张纸是什么纸、墨有多黑、字放在哪"。

## 5. 一句话点单公式

说清楚一支 vibe 片，四段就够：

```
[质感档位] + [节奏] + [图形语言] + [一条特殊要求]
```

例：
- 「宣纸单墨档，3 秒一句，几何抽象，锚词要占画面三分之一」
- 「羊皮纸默片，慢节奏 4 秒一句，剪影为主，结尾留 2 秒黑场」
- 「旧报档案版，紧一点 2.8 秒，线稿拆解，重拍后停 1.5 秒再出术语」

不用每次都报全七维——**没说的走默认**。

## 6. 拿到参考片，怎么反拆（精准描述别人的 vibe）

按顺序看六件事，各记一句：

1. **纸**：偏黄 / 偏白 / 偏灰？有没有明显脏点和暗角？
2. **墨**：是纯黑、深褐还是墨绿？画面里有第二种颜色吗？占多少？
3. **字幕**：居中还是偏左？中文多少字一行？英文有没有斜体？
4. **镜头**：20 秒里画面有没有变大？几乎不动=静止呼吸；缓慢变大=极缓推。
5. **节奏**：数前三句各停几秒。
6. **重拍**：音乐第几秒"换气+砸下"？高潮是字砸出来还是淡出来？

这六条记完，就能用第 5 节的公式复述出来。

## 7. 验收清单（渲染前逐条勾）

- [ ] 抽掉音乐，叙事还成立
- [ ] 锚词能一句话解释，且不是术语
- [ ] 高潮帧（重拍那一帧）锚词**已满不透明**，不是淡入
- [ ] 16.4–17.0 收暗到全黑、静止约 3 帧
- [ ] 全片爆点 ≤2 次
- [ ] 没有弹跳/旋转/花字/快切
- [ ] 字幕 ≤18 字，暗底反白、亮底用深色
- [ ] 纸纹是**静态**的，不逐帧抖
- [ ] 贯穿元素（地面线等）在高潮前收掉，不横切锚词

---

## 8. 三种常见跑偏

1. **全片都在动** → 像企业宣传片。vibe 的"活"来自字幕和元素接力，不是相机一直推。
2. **字幕写太长、太书面** → 像公众号朗读。一句一个念头，别塞两个转折。
3. **纸纹逐帧变化、每张图都弹入** → 那是 Vox 拼贴（A2）的语法，不是 vibe。vibe 的纸是"死"的。

---

## 9. 落到模板

```js
// film.html 顶部 CONFIG
look: "linen",     // P1 parchment / P2 linen / P3 archive
camZoom: 0.05,     // 0=静止呼吸，0.05=极缓推
```

档位只改质感层（纸色/墨色/强调色/颗粒/暗角/字幕位置/锚词字号），
**不改**叙事结构、锚词法、高潮时序——那些在 `setState` 与 CONFIG 的 `beat` 里。
