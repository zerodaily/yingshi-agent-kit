# 历史领域包

## 1 素材来源

- 主要来源：Wikimedia Commons、Internet Archive（Prelinger）、美国国会图书馆、
  各国国家档案馆；检索优先加 `public domain` / `PD-old`
- 授权策略：1929 年前出版物多为 PD；此后需逐件确认
- 抓取方式：Wikimedia API（同 `fetch_photos.ps1`）；Internet Archive 用其 advancedsearch API

## 2 元素类型

| 元素类 | 说明 | 槽位 |
|---|---|---|
| 人物肖像 | 半身像最出效果 | portrait1-2 |
| 场景照片 | 街道、工厂、战场 | hero1-3 |
| 文件/报纸 | 头条、条约、电报 | mini2 / photo1-2 |
| 地图 | 战局图、疆域图、路线图 | scrap1-3 + hero3 |
| 器物 | 装备、工具、货币 | mini1-2 |

## 3 标注词汇

- 年份用中文数字且用「零」；世纪写 `二十世纪六十年代`
- 地名用当时的称呼时要标注（如 `君士坦丁堡（今伊斯坦布尔）`）
- 数字与伤亡：**只用可核实数字**，存疑就写"数千"这类模糊表述

## 4 画面形态

- `board`：多线索事件（红绳连地图与文件）——这是本领域最出彩的形态
- `document`：条约、宣言、电报的呈现
- `assembly`：单一场景照片的展开
- 灾难与战争题材要**克制**：用物件、地点、文件叙事，不做受难者特写

## 5 推荐画风

| 画风包 | 适配度 | 原因 |
|---|---|---|
| 档案调查拼贴（A） | ★★★ | 旧新闻纸 + 半调 + 印章，就是这个领域的原生语言 |
| 复古纸墨（0） | ★★☆ | 适合人物故事，弱在缺乏真实感 |
| 设计拼贴（B） | ★☆☆ | 过于现代，与历史题材气质冲突 |

## 6 领域坑

- 真实惨案题材避免 gore 与受难者特写，把张力放在时间、地点、物件上；
- 肖像的**人物辨识**要写对，不能把 A 的照片配 B 的名字；
- 老照片常有错误标注，交叉验证两个以上来源再用；
- 地图边界随年代变化，用错年份的地图会被历史爱好者当场指出。
