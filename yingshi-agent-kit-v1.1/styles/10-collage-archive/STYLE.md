# 包 A · 档案调查拼贴（collage-archive）

## 一句话

把真实照片处理成半调剪影，贴在旧新闻纸与老海图上，用红绳、图钉和打字机标签把它们连成一条线。

## 适用 / 不适用

- 适用：犯罪、历史、揭秘、灾难、人物调查、品牌考古。
- 不适用：轻松科普、产品种草、需要真人口播出境的场景。

## 图层顺序（自下而上）

| 序 | 层 | 数量 | 说明 |
|---|---|---|---|
| 1 | 底纸 `plate` | 1 | 旧新闻纸 / 档案海图 / 软木板，带污渍、纸纤维、暗角 |
| 2 | 衬底碎片 `scrap` | 1–3 | 撕边纸片，放地图、报纸、表格片段 |
| 3 | 次级照片 `mini` | 0–2 | 小尺寸，压在碎片上，补一个"人证/物证" |
| 4 | 主图 `hero` | 1 | 占画面宽 45–52%，最大最重 |
| 5 | 人物 `portrait` | 0–1 | 竖幅半调剪影 |
| 6 | 胶带 `tape` | 1–3 | 半透明米黄，压在照片与大块纸片的角上 |
| 7 | 标注 `label` / `stamp` / `underline` | 2–4 | 打字机标签条、橡皮章、马克笔下划线 |
| 8 | 红绳 + 图钉 | 1 条 | 最后画，从左到右依次经过图钉 |
| 9 | 全局推近 | — | 成型后一次极缓推近（约 1.4%），不是循环漂浮 |

## 令牌

### 配色

| 用途 | 值 |
|---|---|
| 底纸 | `#d9cfbb`（旧新闻纸） / `#e7dcc2`（更黄的档案纸） |
| 元素纸色 | `#efe7d6` |
| 撕口高光 | `#fdf8ec` |
| 墨色 | `#1b1a17`（主） / `#2a2418`（地图碎片） |
| 信号红 | `#b3271c`（红绳、印章、下划线） |
| 强调红 | `#c0392b`（马克笔） |

只用两级红，不要引入第三个红；不出现蓝、绿、紫。

### 字体

| 用途 | 字体 | 排除 |
|---|---|---|
| 数字/英文标签 | `Courier New`（打字机） | 不要用楷体做档案感 |
| 大号英文标题 | `Impact` / `Arial Narrow` | — |
| 中文标签 | `Microsoft YaHei` 700 | — |

画面内文字一律 HTML/CSS 渲染，任何情况下不交给图像模型。

### 尺寸网格（1920×1080）

- 主图宽 900–960px，中心落在右三分线
- 人物宽 300–340px，落在左三分线
- 碎片宽 500–620px，至少一边出血
- 标签条 padding 14/26，字号 40–96px
- 红绳 3–4px，图钉直径 30px

## 元素引擎

`scripts/photo_to_cutout.py`，跑在 WSL `wan2gp` 环境（rembg + numpy + Pillow 齐全）。

推荐参数（包 A）：

| 参数 | 值 | 说明 |
|---|---|---|
| `dot_pitch` | 7 | 网点栅格；越小越细腻，越容易糊 |
| `screen_angle` | 45 | 印刷网角，黑白半调的经典角度 |
| `density` | 0.7 | 墨量倍率；成品墨量应落在 25–45% |
| `contrast` | 1.05 | 先按 2%/98% 百分位拉伸，再压对比 |
| `gamma` | 1.05 | >1 变浅，<1 变重 |
| `edge` | `torn` | 手撕；要机器裁切改 `cut` |
| `edge_strength` | 0.085 | 抖动 ≈ 3.4px |

抠图失败会自动降级成矩形照片碎片，仍然可用，不必中断流程。

## 节奏（14 秒样板）

所有入场用 GSAP `steps()` 缓动，做出「逐件落位、每两帧一变」的定格手感。

| 时间 | 动作 | 缓动 |
|---|---|---|
| 0.15 | 底纸落定（scale 1.05→1） | `power2.out` |
| 0.90 | 碎片 A 滑入（x −170→0，rot −9→−3.5） | `steps(7)` |
| 1.50 | 碎片 B 落下（y −150→0） | `steps(7)` |
| 2.20 | 次级照片滑入 | `steps(6)` |
| 2.90 | **主图落位**（x 280→0，scale 1.07→1） | `steps(9)` |
| 4.00 | 人物落下 | `steps(8)` |
| 4.90 | 小图落下 | `steps(6)` |
| 5.80 / 6.20 | 胶带下压（scaleY 0→1） | `steps(3)` |
| 6.70 / 7.10 | 标签条滑入 | `steps(6)` |
| 7.80 | 印章拍下（scale 1.7→1） | `steps(4)` |
| 8.50 / 8.85 / 9.20 | 图钉落位 | `steps(3)` |
| 8.60 | 红绳从左到右拉过去 | `steps(7)` |
| 9.90 | 马克笔下划线 | `steps(5)` |
| 10.10–14.0 | 成型后极缓推近（1.014） | `power1.inOut` |

节拍原则：两条标签之间至少留 0.4 秒；印章与红绳之间留一次性静默（stillness before climax）。

## 文字规则

- 画面内文字一律 HTML/CSS；模型只画"画面内容"。
- 单条标签 ≤ 4 个词；全片同时出现的标签不超过 3 条。
- 数字与年份用打字机字体，中文用雅黑/黑体。
- 不写完整句子，不写口播稿。

## 禁忌

- 不做整屏碎片（元素总数 ≤ 8）。
- 不给元素加平滑淡入或长距离缓动，必须停在定格节奏上。
- 不做循环漂浮、呼吸、闪烁。
- 不出现假字、logo、水印、UI。
- 不混入非档案色（蓝/绿/紫/霓虹）。
- 不把文字交给图像模型。

## 交付规格

横屏 1920×1080 / 30fps；竖屏 1080×1920 由横屏工程按产线规则派生；
默认 draft 先审，确认后再考虑 standard。
