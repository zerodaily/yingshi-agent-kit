# 发布规范（publish）

> B 站 Browser Use 发布步骤、发布说明模板、抖音物料、标题/标签/简介规范、草稿箱限制的
> **唯一权威**。主文件只保留「发布前先出草稿确认」的工作流指针。

## 1. 硬规范：标题 / 标签 / 简介

- **标题**：必须带具体数字或反常识钩子（如「500 公斤就能打败法拉利？莲花凭什么成为弯道之王？」），不允许「完整品牌故事传奇历程」这类套话。
- **标签**：8–10 个，覆盖品牌名 + 具体车型 + 关键词；不能只有「汽车 / 科普」这种泛标签。B 站标签不要逗号、不要 `#` 号，每个单独一行，整段粘贴后 B 站按回车逐个添加。
- **简介**：必须含 1 个具体数字 + 1 个互动问题，不空泛。

## 2. B 站发布（Browser Use，禁止 Playwright 脚本自动发）

Playwright 自动发布有风控风险。全部改用 Browser Use 操作用户自己的 Chrome，和真人操作无差别。

### 操作步骤（严格按顺序，不跳步）
1. 浏览器窗口宽度 ≥1200px，窄窗口会导致封面弹窗布局错位。
2. 打开 B 站上传页，上传横屏 final.mp4。上传是异步的，不用等上传完成，传完文件句柄立刻继续下一步。
3. **立刻去传封面**（优先级最高）：等封面弹窗加载 3 秒，用 `input[accept*='image']` 上传 4:3 png；弹出「是否同步 4:3 到 16:9」时点「确认同步」，自动完成 16:9，不用单独再传一次。
4. 填标题、标签、简介：简介框按 `placeholder="填写更全面的相关信息"` 精确定位 contenteditable，不要用最后一个元素瞎找。
5. **铁律**：先向下滚动找到「更多设置」——它默认折叠，必须先点击展开再操作里面内容，否则下面填的全部不生效，这一步每次必做不许跳过。
6. 展开的更多设置里：
   - 创作声明选「含 AI 生成内容」。
   - 互动设置勾选「开启精选评论」（用文本查找 label 元素点，不靠坐标）。
   - **粉丝动态必写**：100 字以内，结合本期内容写一个车迷共鸣的小问题 / 冷知识 / 钩子引导评论。必须通过 `placeholder="有趣的动态描述"` 精确定位 contenteditable，填完用 JS 读 innerText 验证内容真的存在，再点存草稿。
7. 点「存草稿」，不要点「立即投稿」，由用户自己最后发布。

### 踩坑清单
- ❌ 更多设置默认折叠，不展开直接往下填粉丝动态 = 白填。
- ❌ contenteditable 的 div（简介、粉丝动态）普通 type 输入无效，必须用 JS 设置 innerText + dispatch input 事件。
- ❌ B 站封面用 png，用 `input[accept*='image']`；**绝对不要用通用 `input[type=file]`**，会选到视频上传 input 把封面当视频传错。
- ❌ 封面弹窗刚打开时 input 还没渲染出来，立刻传会报错，等 3 秒再传。
- ❌ 操作中不要触发页面跳转，否则弹「确定要离开吗」打断流程。
- ❌ 找输入框不要用 `eds[最后一个]`，必须按各自独有的 placeholder 文本精确定位。
- 封面只传一次 4:3，同步弹窗确认后自动覆盖 16:9，不用传两次。

## 3. 草稿箱限制
- B 站草稿箱硬上限 **30 条**，存满后无法上传新草稿，需要用户手动发布旧稿腾位置。
- 发布前先看草稿箱余量。

## 5. 抖音物料与 60 秒引流片
- B 站长版做完后，自动剪一条 **60 秒引流片段**：从长版挑最炸的 3 个片段拼起来，前 3 秒直接放最精彩画面，语速加快 10%，转场加密，大字幕怼屏幕下方。
- 用 `scripts/teaser_cut.py` 按时间戳截段拼接：

```powershell
python <skill>\scripts\teaser_cut.py <成片.mp4> renders/引流片段_60s.mp4 --segs "12.5-28.3,95.0-139.2"
# --segs 各段合计建议 55–65 秒，超了自动按比例截尾，少了会警告；--srt 可选烧字幕
```
- 引流片是**额外产物，不能替代主片**；主片没到 5 分钟，引流片剪了也白搭。
- 引流逻辑：短片段发抖音引流 → 引导看主页完整长视频（B 站 / 西瓜）。
- 抖音标签用搜索词（「汽车冷知识」「涨知识了」「为什么 XX」），不用大词。
- 竖屏图集按 `composition-and-render.md` 的套图规则抽帧到 `抖音竖屏图集_9x16/`。

## 6. 系列化与涨粉物料（文案写法见 script-rules.md §6.2，这里只列发布落地动作）

- B 站标题 / 开头封面带上「言同学汽车帝国系列第 X 集」序号，结尾预告下一集，形成追剧感。
- 粉丝动态必写一条车迷共鸣钩子（写法与互动结构见 script-rules.md §6.2），对应 §2 第 6 步的粉丝动态填写。
- 评论区预留争议点引导讨论，不写「喜欢请点赞投币收藏」空话。
