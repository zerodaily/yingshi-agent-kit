# Onboarding 访谈清单

> Agent 按此清单逐项询问用户，答案写入 `config/config.json`。
> 【必填】项缺失时不得继续部署；【可选】项可先跳过，填 `"TODO"`。

## 1. 品牌与内容定位【必填】

| # | 问题 | 说明 |
|---|---|---|
| 1.1 | 你的品牌/产品叫什么？做什么的？ | 一句话，例：「XX 白茶，面向女性的可冲泡茶包」 |
| 1.2 | 内容面向什么人群？ | 例：25-40 岁女性、本地食客、宝妈 |
| 1.3 | 目标平台是哪些？ | 抖音 / 视频号 / 小红书 / B站（可多选，影响竖屏/横屏） |
| 1.4 | 想先做哪个选题方向？ | 用于首次冒烟测试的选题 |

## 2. 配音音色【必填】

| # | 问题 | 说明 |
|---|---|---|
| 2.1 | 请提供 ≥10 秒干音样本（wav/mp3） | 用户自己的声音或已授权声音；安静环境录制、无 BGM 无混响；放到 `assets-customer/voice-sample.*` |
| 2.2 | 希望的语速/情绪有没有偏好？ | 可选；默认娓娓道来讲故事风 |

## 3. 视觉风格【必填】

| # | 问题 | 说明 |
|---|---|---|
| 3.1 | 请提供 1-3 张风格参考图 | 用户 IP 形象 / 喜欢的海报风格；放到 `assets-customer/style-ref.*` |
| 3.2 | 主色与画面质感偏好？ | 例：复古做旧红黑 / 清新白绿；无偏好则默认复古纸感 |

## 4. 账号与 API【按需】

| # | 问题 | 何时需要 |
|---|---|---|
| 4.1 | 有无可联网搜索的 Agent 环境？ | 有 → 研究环节直接用；没有 → 需要用户提供一个 LLM API Key（DeepSeek/智谱等，写入 config.json 的 `llm_api_key`） |
| 4.2 | 是否需要自动发布功能？ | 是 → 部署 MediaCrawler（用户需扫码登录各平台，知悉 GPL 与平台条款风险） |
| 4.3 | 代理/网络环境说明 | 仅当访问 GitHub/HF 困难时；模型下载优先走 ModelScope 国内镜像 |

## 5. 工作目录约定【必填】

| # | 问题 | 说明 |
|---|---|---|
| 5.1 | 视频项目放在哪个盘哪个目录？ | 例 `D:\yingshi-projects`；要求所在盘剩余 ≥ 60GB |

---

**完成后**：把以上答案填入 `config.template.json` 另存为 `config/config.json`。
