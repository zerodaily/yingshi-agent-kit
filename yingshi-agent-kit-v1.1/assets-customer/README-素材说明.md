# assets-customer · 客户自备素材

部署时 Agent 会引导你把两个文件放到本目录：

## 1. voice-sample.wav —— 音色样本

- 时长 ≥ 10 秒（30-60 秒更佳）
- 安静环境录制：无背景音乐、无混响、离麦 15-20cm
- 内容随意，用自然的说话状态读一段话即可
- 支持 wav / mp3，重命名为 `voice-sample.wav`（或 .mp3）

## 2. style-ref.png —— 风格参考图

- 1-3 张你喜欢的视觉风格图：自己的 IP 形象、海报、插画均可
- 重命名为 `style-ref.png`（或 .jpg）
- 这是 AI 出图环节模仿的画风基准，选最能代表你想 要感觉的一张

> 提醒：请确保音色与图片素材是你本人所有或已获得授权。
