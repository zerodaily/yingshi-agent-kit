# 领域包（domain packs）

硬视产线是**两个正交维度**的组合：

```
画风（styles/）  ×  领域（domains/）  =  一条片子
看起来怎样            讲的是什么
```

- **画风包**管配色、字体、材质、动效节奏、版式槽位（复古纸墨 / 档案拼贴 / 设计拼贴）
- **领域包**管素材从哪来、用什么元素、标注写什么词汇、有哪些领域特有的坑

「AI 领域 + 档案拼贴画风」和「汽车领域 + 设计拼贴画风」都是合法组合，
所以两者必须分开，不能把领域信息写进画风包。

## 领域包契约

每个领域包一个 `DOMAIN.md`，必须回答六个问题：

1. **素材来源**：这个领域的图从哪来、授权怎么处理、哪些不能用
2. **元素类型**：可以进元素库的物件类别（对应画风包的槽位）
3. **标注词汇**：标签上写什么（年份、参数、单位、人名）
4. **画面形态**：这个领域更适合哪种场景变体（拼装 / 揭示 / 对比 / 文档 / 地图）
5. **推荐画风**：哪套画风和这个领域最搭，哪套要避开
6. **领域坑**：这个领域特有的翻车点

## 目录

| 领域 | 说明 | 状态 |
|---|---|---|
| `automotive/` | 汽车品牌与车型史 | 已实战（捷豹一集） |
| `ai/` | AI 模型、公司、技术演进 | 待实战 |
| `history/` | 历史事件与人物 | 待实战 |
| `_template/` | 新领域从这里复制 | — |

## 新增一个领域要做什么

1. 复制 `_template/DOMAIN.md`，回答上面六个问题；
2. 按该领域策略拉一批图，跑元素引擎进 `library/`；
3. 写 `film.json` 时引用这个库；
4. 不需要改画风包，也不需要改产线代码。
