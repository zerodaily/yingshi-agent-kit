# 包 B · 设计拼贴（collage-design）

## 一句话

把真实照片处理成半调剪影，压在平坦的强色场和彩色卡纸上，用大号字和色块说一句话。

## 适用 / 不适用

- 适用：科技、商业、方法论、科普、产品观点；短视频竖屏为主。
- 不适用：需要档案调查气质的历史/犯罪题材（那是包 A）。

## 与包 A 的区别

| | 包 A 档案调查 | 包 B 设计拼贴 |
|---|---|---|
| 底 | 旧新闻纸 / 老海图 | 单一强色平场 |
| 元素边 | 手撕边，3–5px 抖动 | 机器裁切边，1px |
| 元素纸色 | 旧纸米黄 `#efe7d6` | 奶油白 `#f4ead6` |
| 网点 | 7px | 8px（更粗，更像丝网印） |
| 标注 | 打字机标签、印章、红绳图钉 | 彩色卡纸、大号字、规则线、版式记号 |
| 节奏 | 慢，0.4–0.6s/件 | 快，0.28–0.7s/件，允许 back.out 弹位 |
| 画布 | 16:9 横屏为主 | 9:16 竖屏原生 |

## 图层顺序（自下而上）

| 序 | 层 | 说明 |
|---|---|---|
| 1 | 平色场 `field` | 按语意换底色，带纸纤维颗粒与轻微径向明暗 |
| 2 | 大卡纸 `card` | 奶油白整块，落在画面中部，承载所有照片 |
| 3 | 色条 `strip` | 芥末黄横条，压在卡纸顶边 |
| 4 | 色块 `chip` | 青绿小方块，做节奏打断 |
| 5 | 半调剪影 | 主图最大、人物竖幅、副图小 |
| 6 | 大标题 | 1–3 词，词级入场 |
| 7 | 标签条 `subline` | 深色字压在奶油小卡上 |
| 8 | 规则线 + 版式记号 | 收尾用，给画面"设计过"的证据 |
| 9 | 全局推近 | 一次，约 1.2% |

## 底色语义（按内容选，不要固定一色）

| 底色 | 值 | 语意 |
|---|---|---|
| 焦橙 | `#cf5a2c` | 紧迫、劳动、速度 |
| 芥末黄 | `#d9a441` | 工具、警示 |
| 墨绿 | `#2f4f3a` | 认知、系统 |
| 深紫 | `#4a3560` | 规范、长期 |
| 青绿 | `#2f7f7a` | 协作、执行 |

固定搭配色：奶油白 `#f4ead6`、墨黑 `#141414`。一套片子只用一个底色 + 2 个搭配色。

## 字体

| 用途 | 字体 |
|---|---|
| 大标题（拉丁） | `Arial Black`，退化 `Impact` |
| 中文标签 | `Microsoft YaHei` 700 |
| 小字/编号 | `Microsoft YaHei` 400 |

行高必须 ≥1.15（Arial Black 的字形框大于字号，行高压到 1.0 以下会被 HyperFrames 判为文字重叠）。

## 元素引擎参数

| 参数 | 值 |
|---|---|
| `dot_pitch` | 8 |
| `screen_angle` | 45 |
| `density` | 0.78 |
| `contrast` | 1.18–1.28 |
| `edge` | `cut` |
| `lip_px` / `lip_color` | 3 / `#f4ead6`（奶油白描边） |

## 节奏（12 秒竖屏样板）

| 时间 | 动作 | 缓动 |
|---|---|---|
| 0.15 | 色场落定 | `power2.out` |
| 0.70 | 大卡纸升起（y 130→0） | `steps(6)` |
| 1.25 | 色条展开（scaleX） | `steps(4)` |
| 1.75 | 色块弹位 | `back.out(1.5)` |
| 2.40 | **主图落位** | `steps(8)` |
| 3.60 / 4.50 | 人物、副图落位 | `steps(7)` / `steps(6)` |
| 5.40 / 5.78 | 大标题逐词入场 | `steps(5)` |
| 6.40 | 标签条滑入 | `steps(5)` |
| 7.00 | 规则线拉开 | `steps(4)` |
| 7.30–8.00 | 脚注 + 两个版式记号 | `steps(3–4)` |
| 8.30–12.0 | 极缓推近（1.012） | `power1.inOut` |

## 禁忌

- 一屏不超过 3 个色块；色块是节奏，不是装饰。
- 标题不超过 3 个词，不做整句话。
- 不用渐变、阴影发光、圆角过大（卡纸边角保持锐利）。
- 不做循环漂浮；成型后只有一次推近。
- 文字一律 HTML/CSS，不交模型。

## 交付规格

竖屏 1080×1920 / 30fps 原生；横屏 16:9 由竖屏派生（与产线默认方向相反，
若客户只要横屏，直接用 1080×1920 模板改画布再重排）。
