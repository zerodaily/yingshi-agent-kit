# Vox拼贴风汽车解释视频

## 核心定位
和原来的复古口播故事线并行，做短平快的硬核解释类内容：
- 单集只回答1个尖锐/反常识问题，不铺品牌历史流水账
- 时长3-5分钟，竖屏优先，节奏快
- 视觉是停格纸拼贴风，不是静态图摆着

## 脚本结构（硬规则）
1. **开头0-3s强钩子**：直接甩反常识画面+一句问题，不要自我介绍
   例："这台车开了50年，发动机居然还没坏？"
2. **0-30s抛出问题**：建立悬念，说清楚为什么这个问题值得看
3. **30s-2min拆3个原因**：每个原因配1个独立视觉隐喻
4. **结尾**：给一个冷知识+引导评论"你开过这种车吗？评论区聊"
5. 口播全程短句，写完必须调用humanize-text skill去AI味

## 产线流程（硬顺序，不可跳过）
1. **选题研究**：多源交叉验证事实，关键数字必须有来源
2. **写口播稿**：写完自动过humanize-text去AI味
3. **分镜设计（必做，解决画面单调问题）**：按gbro-collage-broll规范，每段口播对应一个视觉分镜，列成表：
   - 这段核心讲什么道理
   - 视觉隐喻是什么（用一个物体/动作讲明白，不要直接放对应车图）
   - 有几个纸片元素
   - 动效顺序：空场→哪个元素先滑入→哪个后入→最后停在哪
   - 底色选什么（红=震撼/黄=警示/绿=专业/紫=秘密/橙=时间）
   - 所有分镜确认后再进下一步
4. **配音**：IndexTTS2小强音色，语速稍快10%
5. **出图**：Z-Image按分镜隐喻生成黑白半调拼贴剪片，ESRGAN放大
6. **合成**：HyperFrames按分镜动效顺序做停格拼贴组装：空场→元素逐件滑入咔哒就位→停2秒
7. **BGM**：从现有_BGM库选对应情绪
8. **发布**：自动传B站草稿

## 视觉硬规则
- 纯色强底，不要浅米白/深绿旧纸
- 所有纸片元素必须带：清晰裁切边、奶油白细描边、柔和投影、半调网点质感
- 固定机位，不要zoom不要镜头移动不要切镜，就是停格纸拼贴的感觉
- 每个镜头5秒左右，从空场组装到完整画面
- 言同学IP缩小到右下角当小水印，不占主体
