⑥（合成）三步读画风包，其余步骤与画风无关。

## 画风包契约

产线按固定路径读这几个文件：

| 文件 | 内容 | 谁读 |
|---|---|---|
| `STYLE.md` | 画风定义：配色、字体、材质、图层、动效、禁忌 | 人 + Agent |
| `prompts/still-prefix.txt` | 出图前缀（锁风格） | 第 ⑤ 步 |
| `prompts/still-suffix.txt` | 出图收尾（无文字、比例、质感） | 第 ⑤ 步 |
| `motion.yaml` | 入场动作词汇 → GSAP 参数 | 第 ⑥ 步 |
| `elements/manifest.json` | 元素库清单 + 出处与授权 | 第 ⑤.5 步 |
| `library/` | 元素 PNG 库（可复用资产） | 第 ⑤.5 步 |
| `qc.md` | 画风专属验收清单 | 交付前 |

**注意两处例外，不是漏文件：**

- **包 0 不提供 `motion.yaml` / `elements/` / `library/`**——它不使用分层舞台，
  画面是「一张配图 + 文字卡」的整图形态，不拆元素逐件组装。
- **包 0 不提供 `still-suffix.txt`**——它是单前缀出图，前缀末尾的「无任何文字」
  已经是收尾约束。

## 新增一个画风包的成本

1. 复制一个现有包改 `STYLE.md` 令牌；
2. 写两条出图前缀；
3. 复用同一套元素引擎（`scripts/photo_to_cutout.py` 只改参数）；
4. 复制分层舞台模板改图层与配色。

不需要改产线代码、不需要改配音/渲染/发布流程。
