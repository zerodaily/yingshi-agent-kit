# 汽车领域包

## 1 素材来源

- 主要来源：Wikimedia Commons（博物馆藏品照、车展照、街拍）、厂商官方新闻图
- 检索模板：`<品牌> <车型> <年份>`、`<品牌> museum`、`<车型> rally`
- 授权策略：**1960 年前的老照片优先找 Public domain**；现代车型多为 CC BY-SA 4.0，
  必须在 `elements/manifest.json` 记出处与授权，成片交付保留署名
- 禁止使用：其他自媒体的实拍图、厂商宣传视频截帧（除非拿到授权）、带车牌未打码的私车照
- 抓取方式：见 `scripts/fetch_photos.ps1`（Wikimedia API + 限流等待）

## 2 元素类型

| 元素类 | 说明 | 槽位 |
|---|---|---|
| 整车 | 三分之二侧前视角最出效果 | hero1-3 / hero_l |
| 细节 | 徽标、轮毂、发动机、内饰 | mini1-2 |
| 人物 | 创始人、车手（老照片多为 PD） | portrait1-2 |
| 地图/时间线 | 国家地图、赛事路线、年表 | scrap1-3 |
| 文件 | 收购公告、设计图、报纸 | mini2 |

## 3 标注词汇

- 年份：`1922` `1961`（标签数字用打字机字体）
- 性能：`时速 193 km/h` `V12` `50 万公里`
- 事件：`被福特收购` `伦敦车展`
- 单位换算注意：马力/千瓦、英里/公里在标签上只保留一种，别混

## 4 画面形态

汽车以**实物为主角**，最适合：

- `assembly` / `wide`：整车落位，占画面宽 45–56%
- `left`：整车靠左、文字列靠右（适合讲参数）
- `board`：多车并列 + 红绳连年代（适合"家族谱系"）
- `document`：讲收购、破产、停产这类没有车可拍的信息点

## 5 推荐画风

| 画风包 | 适配度 | 原因 |
|---|---|---|
| 档案调查拼贴（A） | ★★★ | 老照片 + 半调 + 红绳图钉，天然适合车型史 |
| 设计拼贴（B） | ★★☆ | 现代车型配平色场很有设计感，但历史感弱 |
| 复古纸墨（0） | ★★★ | 现行主力，插画风不依赖真实照片 |

## 6 领域坑

- 现代车型照片多为 CC BY-SA，**同一集里混 PD 与 CC BY-SA 时，署名清单别漏**；
- 车头朝向混乱会显得乱：同一集里尽量让主图车头朝同一侧；
- 车型换代辨识难，标签必须写清年款，否则老车迷会在评论区纠正；
- 车牌是敏感项，导出的元素里若含清晰车牌，先用补丁盖掉。
