# 封面与静态排版规范（cover-and-layout）

> 本文件是「封面构图、配色 token、字体角色、静态卡片排版、反 AI 模板套路」规则的
> **唯一权威**。言同学 IP 的外貌标准定义在 `image-pipeline.md`，本册只管它在封面/卡片上的落位。
>
> **封面基准（2026-10-23 回归已验收旧风）**：以五菱、大众、日产、凯迪拉克四张定稿为准的
> 复古剪报线稿风——米黄旧纸底 + 撕边毛边纸卡 + 黑白半调/木刻排线车图 + 黑色钢笔线稿人物
> + 磨损做旧超大标题 + 朱红印章。废弃此前「深墨绿充墨扁平插画 + 黄肤扁平人物 + 硬黑矩形框」
> 的跑偏口径。视觉校准见 `assets/covers/style-reference-modern-16x9.jpg` 与
> `assets/covers/style-reference-modern-9x16.jpg`（校准图待下次出新封面时一并更新）。

## 1. 动手前先定 token（frontend-design 纪律）

排封面或静态卡片前，先在草稿里定死再写代码，不要边写边配色：
- **配色**：先定 4–6 个命名 hex（纸底、主色、点缀红、墨色、反白），全片复用同一套，不临时取色。
- **字体角色**：标题（楷体 KaiTi / 做旧粗体英文）、副标题（宋体 SimSun）、数字（Anton 类粗体）、标签（黑底白字粗体条），各自只担一个角色。
- **对齐**：先定主列宽度、边距、对齐基准，再摆元素。
- **一屏一个重点**：一张封面/卡片只让一个东西先被看到（车、或大标题、或言同学），其余退为配角。

## 2. 封面配色 token（禁止反色，禁止整幅充墨）

| 角色 | 取值 | 说明 |
|---|---|---|
| 纸底 | `#efe2c1` / `#fbf3d8` 米黄旧纸 | 标题区、留白区与纸卡外主底，叠纸纹噪点 |
| 墨色 | `#1b1b1a` 近黑 | 人物线稿、车轮廓、结构线、排线阴影 |
| 灰度 | 旧照片灰阶 + 半调网点 | 车/发动机/场景主体质感，不是纯色平块 |
| 主色（轮换） | 墨绿 `#1c3a32` / 朱红 `#b8341c` / 宝蓝 / 芥末黄，按选题选一种 | 只用于标题字、局部充墨或背景色块平衡，不大面积铺满整车 |
| 点缀 | `#c0392b` 朱红 | 印章、一处重点、小色块 |
| 亮部 | `#f8f1de` 米白 | 纸卡切口、线稿留白、半调高光 |

- 车与机械以**黑白半调、旧照片颗粒、木刻排线**为主，可在局部平涂一种主色（如大众后半宝蓝、
  凯迪拉克底部绿色刷痕、日产深墨绿赛道）；**禁止**把整台车涂成单一深墨绿平块。
- 标题放在大面积米黄纸面上；主色只承担标题、局部色块和点缀，形成纸底、墨线、灰度与一点主色的对比。
- 封面不是纯白线稿；纯白只允许作为纸卡内高光，不能作为封面默认底色。
- 背景平衡块用朱红大圆、赛道场景、绿色刷痕等服务构图；**禁止**在车身后立一块纯色矩形挡板。

## 3. 封面标题结构（固定三段，不做符号堆叠）

标题字用磨损做旧粗体，带颗粒、裂纹和轻微油墨不均；不要用光滑电脑字体直接铺满。

**第一层：超大中文品牌名（或英文品牌名，二选一为主视觉）**
**第二层：小号英文品牌名 + 中文钩子，配一条贯穿细线**
**第三层：年份或关键数字**

- 三层靠字号、留白、横线和位置建立层级，不把 `——` / `·` 当作标题正文装饰。
- 已验证的信息关系参考：`现代` → `HYUNDAI · 从修配厂到世界第三 · 2026`；
  中文品牌名先被看到，英文和钩子退为第二条信息。
- ❌ 不允许只写两个中文大字；标题必须带具体数字或反常识钩子（如「500 公斤就能打败法拉利？」），不写「完整品牌故事传奇历程」这类套话。
- 中文品牌名居上，英文品牌与副标题钩子在其下，年份/关键数字融进副标题。

## 4. 封面人物 IP「言同学」的落位

- 外貌唯一标准见 `image-pipeline.md`，完整提示词见 `references/cover-ip-prompt.md`。
- 「言同学」是**黑色钢笔线稿**人物：黑墨填发、黑 T 黑裤、白线勾体积；保留照片原型的辨识特征
  （细框矩形眼镜、上唇小髭 + 下巴山羊胡、黑色乱发发丝丝、白圈闪电 T 恤 logo、斜挎带、黑表黑腕带）。
  线稿里黄肤被墨色替代，不单独铺肤色块；不是全黑剪影，也不是写实人像或大头吉祥物。
- 人物以墨线和留白勾出体积，脸、耳、手靠白线高光区分，不被主色背景吞掉。
- 必须和车发生物理互动，动作承担叙事：蹲在车尾抱箱装车、握方向盘过弯、俯身调试发动机、
  拉安全带、靠车门、指发动机、站在碰撞装置旁。身体要有扭转和重心，不能僵硬站在旁边看。
- 人物占画面 **1/4–1/3**，动作必须承担叙事，不能只是站在旁边当装饰。
- 车和人物必须出现在同一张生成场景里（路线已拍板：同框一张出；车单独出 + PIL 贴人的拆层路线废弃）；不要把车图和人物图分别生成后硬拼。
- 生图不含任何文字，标题、数字和标签由 HTML/CSS 叠加。
- 顶部至少留出画面高度约 28%–32% 的安静米黄纸面，用于超大中文标题。
- 印章：右下角白底朱红边框磨损「言同学」；左图右文款可移左下角。
- ❌ 封面没有「言同学」、只有车和文字，属于违规。

## 5. 四套模板轮换（不要每次同一个版式）

每次从下面选一种，或混搭，保证系列感但不单调：

1. **经典款**：顶部超大磨损中文（或英文）品牌名 → 小号英文品牌与钩子 → 撕边纸卡内黑白半调车与黑线稿「言同学」互动的完整场景 → 右下角白底朱红印章。
2. **左图右文款**：左侧 2/3 是撕边纸卡内的车与「言同学」互动场景，右侧 1/3 竖排品牌名 + 副标题。
3. **沉浸款**：「言同学」和车占满整个画面，品牌名小一点放顶部角落，印章右下角。
4. **对比款**：上下或左右分屏，老车 vs 新车；「言同学」在同一个人物层里指两边，品牌名放中间。

## 6. 静态卡片与字幕排版

- 静态画卡只用于封面、极短结论句和片尾。正片叙事不得每场都使用「居中画卡 + 下方说明」，
  该结构是 PPT 感的主要来源。正片使用 `visual-craft.md` §6.1 的满幅、分栏、特写和证据叠放骨架。
- 正文不用 `<br>`，用 max-width 自然换行。
- 行宽控制在舒适阅读范围；标题字重本身就是视觉元素，不靠额外加粗堆层次。
- 编号只在真流程/时间线上使用；并列条目不要为装饰加 `①②③`。
- 文案说人话、主动语态；删书面套话（去 AI 味见 `script-rules.md`）。
- 竖屏安全区：顶部 10%、底部 25%、右侧 10% 被 UI 遮挡；核心内容（图 + 主文字）放中间 15%–70% 高度区。
- 竖屏字幕放中间偏下（约 60%–65% 高度），不贴底部；竖屏标题 ≥76px，正文 ≥44px（静音刷看也要一眼看清）。

## 7. 反 AI 模板默认套路清单（出现即改）

以下是 AI 生成排版最容易滑向的模板感，封面/卡片里逐项排查：
- ❌ 米色底 `#F4F1EA` + 陶土 `#D97757` 这套默认配色组合。
- ❌ 全大写英文 eyebrow 小标签放在标题上方。
- ❌ 用 `A · B · C` 中点串代替真正的排版层级。
- ❌ 用 `词 — 片段` 长破折号把标题硬连成一句。
- ❌ 等宽字体小标签满屏贴。
- ❌ 链接尾巴 `→` 装饰性堆叠。
- ❌ 无理由编号、满屏分隔线、对称到呆板的居中。
- ❌ 每张图都弹入落下、千篇一律「顶部大字 + 中间车 + 小人站左边」。
- ❌ 6px 硬黑矩形边框把车图框成 PPT 幻灯片；主体必须放在撕边毛边纸卡内，纸外是旧纸底。
- ❌ 整台车涂成单一深墨绿平块；车要有黑白半调、灰度体积和排线阴影。

## 8. 明确不适用（网页交互规则，不迁移到视频帧）

以下来自网页 UI 规范，视频封面/卡片**不做**：hover 悬停动效、键盘焦点样式、响应式断点、
移动端适配、`prefers-reduced-motion` 降级逻辑、点击态与按钮交互。

## 9. 封面先行闸门
- 新项目先出 **6 个尺寸封面**（1:1 / 16:9 / 9:16 / 4:3 / 3:4 / 4:5）连同口播稿交用户确认。
- 六个尺寸分别原生生成或重新构图；只能裁切校稿，不能把 4:3 机械裁成最终六尺寸。
- 用户确认 IP 形象和标题排版之前，禁止进入配音、出图、渲染。
