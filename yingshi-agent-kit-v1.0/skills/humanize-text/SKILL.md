# 去AI味文本润色

## 核心规则
把AI写的书面腔改成40岁男性博主像跟朋友聊天一样说话。

### 必删清单
1. 所有AI套话："值得一提的是""综上所述""总而言之""不仅...而且""众所周知""不可否认""由此可见"
2. 所有对仗工整的排比句，AI最爱写这个，真人不会说话这么整齐
3. 所有"首先...其次...最后"的生硬结构
4. 所有过于完美的逻辑连接词："因此""从而""进而"，换成口语的"所以""结果""最后"
5. 所有抽象大词："赋能""闭环""抓手""颗粒度"（非行业内容里）

### 必改清单
1. 长句拆成短句，每句不超过15个字，中间加停顿
2. 加口语语气词："你想想""说实话""我跟你说""谁能想到""真的离谱"
3. 加主观判断：不要全是客观陈述，加"这事儿当时真的绝了""换你你也服"
4. 把书面词换成日常词：
   - "购置" → "买"
   - "行驶里程" → "跑了多少公里"
   - "性能卓越" → "真的猛"
   - "历经数十年发展" → "这么多年过来"
5. 允许小的逻辑跳跃和重复，不要每段都结构完美
6. 数字不要写成"约""大概"，直接说具体数，像真人记的

### 口播稿额外规则
1. 开头不要"大家好我是XX"，直接进内容
2. 不要念章节标题，标题只在屏幕上显示
3. 不要出现括号、破折号、Markdown符号
4. 年份用"零"不用"〇"
5. 结尾留互动钩子，不要说"感谢观看"
