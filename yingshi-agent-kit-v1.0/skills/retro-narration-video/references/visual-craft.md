# 镜头与画面动态规范（visual-craft）

> 本文件是「镜头节奏、真实素材层、揭示动作、转场」规则的**唯一权威**。主 SKILL.md、
> 其他分册不再重复写秒数和镜头动作。解决的核心问题：画面静态、一个木刻画摆到底，
> 看起来像 PPT。

## 1. 开工先选风格（BRIEF 里定死，不混着来）

| 风格 | 适用 | 镜头基调 | 参考工程 |
|---|---|---|---|
| 动态纸墨（默认） | 品牌历史长故事、人物传记，5–8 分钟长片 | 满幅木刻画或真实空镜打底，纸片/人物/标注分层，镜头随旁白换景别 | 复古纸墨 v2 样片 |
| Vox 拼贴 | 硬核解释、反常识冷知识，仅限 60–180 秒短片 | 固定机位桌面拼贴，stop-motion 一拍二，2–3 秒一个视觉事件 | vox 拼贴试片 |
| huashu 艺术动态 | 视觉冲击强、节奏快的 15–180 秒短片 | 相机平滑运动 + 元素步进，硬切快推/横移，荧光笔/红圈/数字砸入 | huashu-art-motion |

三种风格的镜头语法见第 6 节；选完一种，全片不中途切换。
B 站 5–8 分钟长片只用“动态纸墨”；Vox / huashu 作为独立短片或引流片制作。

## 2. 节奏与镜头时长（唯一口径，其他位置一律引用本节）

### B 站长版横屏（1920×1080，5–8 分钟）
- 镜头节奏：**每 4–7 秒一个镜头**，单镜头不得超过 8 秒。
- 镜头数量：5 分钟至少 **45 个镜头**，8 分钟至少 **70 个镜头**；时长更长按比例增加，
  **禁止同一张图连续占用两个镜头**。
- 一个镜头内必须有 1–2 个随念词发生的视觉事件：换景别、主体入画、证据推近、
  标注落位或信息增量。只有 Ken Burns 和淡入不算镜头事件。
- 禁止：一张居中画卡停到底、全程匀速慢推冒充运动、每场固定「标题 + 居中图 + 说明」。

### 抖音竖屏短版（1080×1920，60–90 秒）
- **每 2–3 秒必须有一次视觉变化**（字弹出 / 数字跳动 / 箭头滑动 / 空镜切换 / 卡片位移），每 15 秒插一个小钩子。
- 只留最炸的 3 个点，砍掉历史铺垫。

### 通用节奏纪律
- 动作对齐念词：荧光条、打字、描线、数字弹出的速度锁在口播念词上，不锁音乐拍点。
- 开镜不空台：镜头开场到第一个动效锚点不得超过 1.5 秒；没有真实空镜/上一镜元素延续时，不许空画布干等。
- 同屏主体组 ≤3，每镜至少留一个空象限；一屏只放一个 hero 造型。

## 3. 真实素材层（治 PPT 感的核心，路线 A）

**画面的「活」优先来自真实素材本身的运动**（握方向盘、街景移动、车流、冰雪路、
老车行驶）。没有真实运动素材时，必须改用有叙事目的的景别变化、分层揭示和信息增量；
不能只把一张静态木刻画匀速推拉，静态图再运镜仍然是 PPT。

### 3.1 层级结构（自下而上）
1. **B-roll 空镜层**：真实视频循环打底，cover 铺满。
2. **米色 scrim 雾层**：`rgba(239,226,193,0.55~0.62)`，压在空镜上保证上层纸卡和字清晰；空镜做低饱和、轻微压暗，不喧宾夺主。
3. **主体/纸片层**：木刻主体、档案照片、人物剪影、标签与标注浮在上层。主体应
   满幅裁切或占据 45%–75% 画框；禁止默认缩成居中小画卡。
4. 空镜只做极缓 Ken Burns（scale 1.0→1.05），不做大动作、不做旋转模糊。

### 3.2 视频层技术规则（HyperFrames，踩过坑）
- 定时空镜 `<video>` 可以位于主壳或场景内部，但必须保留 `class="clip"`、`muted playsinline`、
  `data-start/data-duration`；同一段内容只给视频或其外层其中一层设置时间窗，不能两层都设。
- **素材短于镜头时长时，必须先用 ffmpeg 预循环烘焙到精确窗口长度**，再交给引擎：
  离线渲染器对短素材的 loop 取模/尾段抽取不可靠，会抽成近静止冻屏。
  ```powershell
  ffmpeg -y -stream_loop -1 -i <源.mp4> -t <镜头秒数> -r 30 -g 30 -c:v libx264 -pix_fmt yuv420p assets/broll/<镜头id>.mp4
  ```
- 换素材后清抽帧缓存：`%TEMP%\hyperframes-extract-cache-u\hfcache-*`，避免命中旧帧。
- 选片优先选**本身在运动**的镜头（行驶、车流、行人、起伏路）；固定机位、只有远处轻微动静的镜头在 scrim 下看不出动，不用。
- 视频的调色、颗粒、暗角和虚化使用 `npx --yes hyperframes@latest media-treatment`，
  不要用 CSS filter 冒充正式 media treatment。

### 3.3 素材缺口兜底
- 专属空镜（工厂总装线、碰撞测试慢动作、车型特写、激光雷达、品牌工厂）采不到时，
  该段用满幅木刻插画的景别变化、分层纸片、数字滚动和红圈标注撑，
  并在 `notes/` 登记缺口，不硬凑近静止空镜。
- 不允许全片零真实素材、只有动效 + 静态图（= 讲 PPT）。

## 4. 揭示动作轮换（防止观众预判下一步）

分镜时先列一张揭示动作表，同一套揭示序列**连用不超过 3 次**：

| 类型 | 动作 |
|---|---|
| 直接在 | 随切点出现，不弹不落（档案照片、剪报默认） |
| 推近 | 快推 0.28 秒推近 18–32% 后停，对准要读的那一句/数字 |
| 横移 | 同倍率 0.30 秒横移到下一张，不匀速慢漂 |
| 荧光笔扫 | 一行 1.5–3 秒，跟念词扫完 |
| 红线/红圈 | 下划线 0.5–1 秒画完；红圈约 1 秒一笔，首尾不闭合、略交叉 |
| 打字标签 | 约 13 字/秒，一拍二 |
| 盖章/砸入 | 数字块先落定 0.24 秒，稳住那一帧数字才弹；单位占位只动 opacity |
| 滑入 | 仅沿时间线追踪时，下一张从画外 5–15° 倾斜滑入放平，约 0.8 秒 |

## 5. 转场

常用 6 式，一个边界只用一式：
1. **硬切**：占绝大多数，切点卡在旁白句读上。
2. **沿线索平移**：相机沿一条红线/视线水平移动 1.3–1.8 秒，长尾缓动，下一张斜滑入放平。
3. **推进进图 → 硬切成同一张的高清扫描**：1.0–1.4 秒，S 型缓动。
4. **从单张照片拉出 → 露出整面拼贴**：约 1.0 秒，起步快、长尾落定。
5. **地图色块生长 / 路线描线**：2.5–3.5 秒，一拍二，线头带实心红点。
6. **纸沿弧线滑入**（近似翻页/抽纸），带阴影变化。

**禁止冒充 Vox 的模板动作**：撕纸转场（样片里从未出现）、每张图都弹入落下、纸纹逐帧抖动、
每个 section 都 fade-and-slide-up、每张卡都加 hover 式入场。

## 6. 三种风格专属语法

### 6.1 动态纸墨
- 米黄旧纸底 + 木刻版画或真实 B-roll 打底；朱红只做标注、印章和运动线索。
- 主体不得默认缩成居中小画卡。使用满幅出血、左图右文、局部特写、证据叠放、
  人物侧栏、巨号数字等镜头骨架；同一套骨架不得连续使用三次。
- 章节内部至少交替使用三种构图：环境镜、主体镜、证据/数字镜。每次旁白转折至少
  发生一次景别或信息层变化。
- 空镜层按第 3 节铺，scrim 控制在 0.40–0.58；真实运动必须可见，不能被厚雾压成静图。
- 切镜使用同一横向 current，优先 0.28–0.38 秒的 partial travel；章节边界才允许
  换方向或使用更强的转场。
- 静态居中卡片只允许用于极短的结论句或片尾，不得作为常规叙事镜头。

### 6.2 Vox 拼贴
- 米色牛皮纸桌面，组装阶段相机固定；证据切换时可沿桌面平移，但单个组装镜头内不做
  无目的环绕或旋转。黑白半调剪片 + 图钉 + 红印章 + 红线连线 + 打字机标签。
- 元素从空桌面错峰组装滑入，stop-motion 一拍二，约 7 秒就位后保持。
- 两层帧率：相机层连续平滑，元素层 12fps「动-停-动」步进；不要全部 60fps 丝滑。
- 颜色克制：主体是纸白、近黑、一种红，另加一种强调色；荧光黄只用来划重点，不大面积铺底。
- 要读的字放在最上层、最后画，不被后放上来的照片/夹子盖住。
- 同一事件的正式动作只演一次：全景演过的，推近后不再重演。

### 6.3 huashu 艺术动态
- 相机 24fps 平滑运动，元素 12fps 步进；硬切 + 快推/横移。
- 荧光笔扫重点、红圈手绘、数字砸入等编辑器元素丰富，但同一时刻只突出一个重音。
- 缓动：长距离找下一张用对称 easeInOutSine；拉出揭示/沿线索追用长尾 `cubic-bezier(.33,0,.2,1)`，不用线性。

## 7. 镜头自检（渲染前过一遍）
- [ ] 每个镜头都有真实运动来源（空镜运动 / 卡内动效 / 推近横移），不是一张图停到底。
- [ ] 节奏秒数符合第 2 节对应平台口径。
- [ ] 揭示动作没有连续 3 次以上用同一种。
- [ ] 空镜素材已预循环烘焙到镜头长度，无冻帧；换素材清过缓存。
- [ ] 同屏主体 ≤3，文字在最上层且清晰。
- [ ] 没有撕纸转场、全员弹入、纸纹抖动等模板动作。
